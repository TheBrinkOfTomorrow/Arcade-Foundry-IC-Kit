# Arcade Foundry: Insert Coin Kit

The Swift engine shared by the Apple apps that run Arcade Foundry's game
cores:

- [Arcade Foundry: Insert Coin](https://github.com/TheBrinkOfTomorrow/Arcade-Foundry-Insert-Coin),
  the library and player with your own ROM sets.
- Arcade Foundry: Game Cabinet, the slim player that Arcade Foundry: Game
  Director sets up on your devices for a linked race (not released yet).

It runs a game: loads a core (`Core/`), drives it frame by frame with sound
and controls (`Session/`, `Audio/`, `Input/`), draws it (`Render/`, `VR/`),
records replays (`Video/`), and knows every game, where its ROM set and
saves live and the player's settings (`Library/`). `Play/` has the window a
game plays in and its pause menu.

## Using it

The kit is a folder of sources, not a Swift package: each app compiles it
into its own module, so nothing in it needs to be `public`. An app adds it
as a git submodule (at `kit/` in both apps) and, in its XcodeGen spec:

```yaml
settings:
  base:
    SWIFT_OBJC_BRIDGING_HEADER: ../kit/Sources/Core/Bridging.h
    HEADER_SEARCH_PATHS: <cores-common>/include   # afcore.h, the cores' C interface
targetTemplates:
  App:
    sources:
      - path: ../kit/Sources
```

Code that only one app needs is behind a compilation condition: `CABINET`
for Game Cabinet (no iCloud, the Game Director's link messages).

`Library/GameList.swift` is generated by Insert Coin's `scripts/gen_games.py`
from its `games.toml` and the cores' own: edit those, not this file.
